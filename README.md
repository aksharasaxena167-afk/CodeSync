🚀 CodeSync — Real-Time Collaborative Code Editor

CodeSync is a modern browser-based collaborative IDE that enables multiple users to code together in real time with live synchronization, multi-language execution, shared rooms, chat, and an IDE-inspired interface.

✨ Features
🔥 Real-time collaborative code editing using Socket.IO
👥 Room-based multi-user sessions
💻 Monaco Editor integration (VS Code editor engine)
⚡ Multi-language code execution using Judge0 API
📂 Multi-file & folder support
💬 Real-time collaborative chat
🌙 Dark/Light theme support
💾 Auto-save & persistent workspace
📥 Download files/projects
👤 Live user presence & activity tracking
🖥️ Terminal-style output console

⚙️ Installation & Setup
- Clone Repository
git clone https://github.com/aksharasaxena167-afk/codesync.git

Frontend Setup
cd client
npm install
npm run dev

Frontend runs on: http://localhost:5173

Backend Setup
cd server
npm install
node index.js

Backend runs on: http://localhost:5000
